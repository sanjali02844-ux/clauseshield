CLAUSESHIELD WEBSITE PROTOTYPE
===============================

CONTENTS
- index.html: all website sections and interface structure
- style.css: responsive visual design
- script.js: demo interactions and calculations
- assets/: place any additional images or logos here

HOW TO OPEN
1. Extract the ZIP file.
2. Open the ClauseShield-Website folder.
3. Double-click index.html (or right-click and open with Chrome/Firefox/Edge).
4. For best results, use a modern browser and an internet connection for the optional Google Fonts.

HOW TO UPLOAD
Upload the extracted ClauseShield-Website folder to the hosting service shown in your tutorial.
If the service asks for a ZIP, upload the ZIP without extracting it.
If it asks for a project folder, upload the extracted folder. Keep index.html at the folder's top level.

IMPORTANT LIMITATIONS
This is a front-end demonstration. It does not connect to an AI model, legal database, OCR service, cloud storage or lawyer network. The audit scenarios use illustrative sample logic, not legal determinations. No lease or photo is sent to a server by this prototype. The WhatsApp action opens a pre-filled message; the user must review and send it themselves. The print action uses the browser's Print / Save as PDF feature.

LEGAL NOTICE
ClauseShield is an informational student prototype, not legal advice. The Model Tenancy Act, 2021 is a model framework; applicability depends on the relevant state and current law. Do not present sample verdicts or demo figures as guaranteed legal outcomes.
